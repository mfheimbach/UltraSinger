# Pre-pipeline studies (archived)

One-off studies and tools written for the old monolithic run() and its Settings/cache layout
(eval_work/cache/<song>/rmvpe_*.json, settings overrides like whisper_model=...). They document
how earlier findings were made (see the roadmap) but do not run against the pipeline as is.
Port a tool when it is needed again: presets + step.param overrides, stage caches.
