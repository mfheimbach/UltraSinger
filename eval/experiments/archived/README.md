# Archived tools (superseded or failed; kept for the record)

- `fit_line_breaks.py`: logistic fit of the line-break model from charts. Superseded by the tuner
  (`eval/tune.py`, group "line breaks"); it predates the pause_floor/prob_floor/... parameters and
  does not run against the current LineBreakModel.
- `golden_longest_notes.py`: "longest notes become golden" rule; tested, made scores worse.
